## About

This repo collects detailed write-ups of vulnerabilities I've found and responsibly disclosed across open-source projects and bug bounty programs — root-cause analysis, impact, and remediation for each, published after the vendor has had the chance to address them. Payloads and target-identifying details are redacted where disclosure terms call for it.

Full, less formal breakdowns of some of these also go up on [Medium](PASTE_YOUR_MEDIUM_LINK_HERE).

## A Note on Redaction

Every report in this repo has been through responsible disclosure with the affected project or vendor before publication. Where a disclosure requires it, target identity, version specifics, and working exploit payloads are withheld or generalized — the goal is to document the *pattern* of the bug so other researchers and maintainers can learn from it, not to hand out a working attack.
